# Omnifood 🍱

Omnifood is a responsive landing page for a fictional AI-powered food subscription service. The project was built to practice modern HTML and CSS techniques, responsive web design, layouts, and creating a polished multi-section website.

## 🌐 Live Demo

- [View Live Demo in netlify](omnifoodsam.netlify.app)
- [View Live Demo in GitHub](https://mirghasemi8.github.io/omnifood-project/)

## 📖 About the Project

Omnifood is a fictional food subscription service that uses AI to create personalized meal plans based on the user's dietary preferences and nutritional needs.

This project focuses primarily on building a modern, responsive website from scratch using HTML and CSS.

The website includes multiple sections that present the service, explain how it works, showcase meals, display customer testimonials, and provide pricing and subscription options.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Modern landing-page layout
- Hero section with call-to-action buttons
- Featured-in section
- "How it works" section
- Meal and nutrition showcase
- Customer testimonials
- Image gallery
- Pricing plans
- Call-to-action section
- Footer with navigation and social links
- Responsive navigation menu
- Smooth scrolling
- CSS animations and transitions

## 🛠️ Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
- Media Queries
